# Broke UP Interactive Demo v2

双击 `start-demo.command` 即可启动。电脑会打开 `http://127.0.0.1:4173`，同一 Wi-Fi 下的手机访问启动脚本打印出来的 LAN 地址（例如 `http://192.168.1.8:4173`）。

- 前端：`frontend/`
- 公共网关：`public-server.mjs`（把页面与 `/api` 合并到一个端口，支持公网演示）
- Mock API：`backend/server.mjs`
- API 地址：本地拆分开发使用 `:8787`；通过公共网关访问时统一走同源 `/api`
- 数据口径：林澈、周屿、南乔均为合成人物；推理结果为演示用预置结果。

本 Demo 不包含真实登录、录音上传、系统通知、电话、陌生人匹配或外部模型密钥。

## 当前体验结构

- 桌面端采用 390 × 844 的 iPhone 15 Pro 内容尺寸；手机端自动铺满屏幕。
- 讲述阶段先建立最小 TA 档案，再选择「连续倾诉」或「逐题回答」。逐题模式包含 9 个具体问题，答案选项只作为表达方向。
- 第 3、6 个细节后出现阶段性回顾，明确展示「我已经知道什么 / 我还想知道什么」；用户可以继续，也可以下次再说。
- 关系画像形成后不会直接跳到打卡，而是经过独立启程页，说明后续如何同时处理情绪、现实行动与真人连接。
- 第二阶段固定保留「交流 / 习惯 / 同路 / 手账」四个 Tab，分别承接线索分析、习惯成长、同行连接和关系档案。
- 所有行动推荐回到前期讲述中被捕捉并确认的兴趣、愿望或被搁置的自己，避免退化为通用习惯管理。
- 陪伴阶段以 21 天为一个周期，把情绪反扑、现实项目、同行连接与可追溯记忆放在同一条链路中。
- 现实项目支持游泳、读书、攀岩、滑雪四套合成演示包，并保留「我现在怎么看 TA」的纵向变化。
- 第 21 天先询问是否放下；选择「还没有」会平等延长 5 天，不清零、不判失败。
- 模拟电话可拒接、可中途挂断；不拨电话仍可进入结案。
- 手机顶部 `•••` 可快速切换天数、现实项目和重置演示。
